# Windows installation

1. Download `Spaceline-Setup-0.9.6.exe` from the GitHub Releases page.
2. Run the installer. It creates Start Menu and optional desktop shortcuts. No PowerShell or separate Python installation is needed.
3. On first setup, configure the Firebase Web values in the `.env` file in the Spaceline installation folder. Use `FIREBASE_SETUP.md` for instructions.
4. Launch Spaceline from the Start Menu or desktop shortcut. Your workspace data is stored separately in `Documents\Spaceline` and is not removed when the app is uninstalled.

The installer is per-user and does not require administrator rights. The Windows build is generated by GitHub Actions from the tagged source.
