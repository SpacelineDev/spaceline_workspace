# Windows installation

## Download and install

1. Open the [official Spaceline GitHub Releases page](https://github.com/srijanmuddam16-hub/spaceline_workspace/releases).
2. Download `Spaceline-Setup-0.9.6.exe` from the latest release (currently v0.9.6).
3. Run the installer. It creates Start Menu and optional desktop shortcuts. The packaged installer is intended to avoid requiring a separate Python installation or a PowerShell launch.
4. On first setup, configure the Firebase Web values in the `.env` file in the Spaceline installation folder. Use [FIREBASE_SETUP.md](FIREBASE_SETUP.md) for instructions.
5. Launch Spaceline from the Start Menu or desktop shortcut. Your workspace data is stored separately in `Documents\Spaceline` and is not removed when the app is uninstalled.

The installer is per-user and is designed not to require administrator rights. The Windows build is generated by GitHub Actions from the tagged source.

## Windows security notice

The v0.9.6 EXE installer is currently **unsigned**. Windows Smart App Control may block it. Smart App Control does not offer a per-app exception, and GitHub Releases does not automatically make an unsigned EXE trusted. Do not disable Smart App Control or other Windows protections to install it. If Windows blocks the installer, stop and wait for a future release distributed through a trusted signing route.

We are investigating free options, including Microsoft Store distribution as an MSIX package and eligibility for the SignPath Foundation open-source signing program. Neither route is approved or active for v0.9.6, and neither should be considered a guarantee until an actual signed package is published.

## Uninstall

Use **Settings → Apps → Installed apps → Spaceline → Uninstall** (or the Windows Start Menu uninstall shortcut if shown). Your workspace data in `Documents\Spaceline` is separate; back it up or remove it manually only if you no longer need it.
