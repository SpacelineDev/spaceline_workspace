# UX review

1. Identify the user's task and shortest successful path through the current UI.
2. Inspect empty, loading, success, error, disabled, destructive and narrow-screen states.
3. Remove fake controls and labels that imply unsupported functionality.
4. Prefer clear hierarchy, consistent actions, readable contrast, keyboard support and useful feedback.
5. Preserve existing visual language unless the user asks for a redesign.
6. Verify changed UI in a browser or test harness where available; do not claim visual QA from source inspection alone.
