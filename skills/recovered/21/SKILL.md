# Python mentoring

1. Explain the concept in plain language, then show the smallest runnable example.
2. When debugging, explain the root cause and a minimal corrected version.
3. Build from basics toward functions, data structures, modules, testing and scientific Python.
4. Include expected output and one short practice exercise when teaching.
5. Do not silently replace the learner's approach with advanced abstractions they have not learned yet.
