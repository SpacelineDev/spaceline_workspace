# Prompt engineering

1. Extract the real goal, intended model/tool, audience, context and required output format.
2. Add only constraints that improve reliability; avoid bloated repetitions and contradictory instructions.
3. Separate instructions from reference data and define what to do when information is missing.
4. Include acceptance criteria, edge cases and a small example when useful.
5. For agent prompts, define tools, permissions, approval gates, stop conditions and reporting requirements.
6. Avoid claims that a prompt can grant capabilities, bypass subscription gates or create unavailable integrations.
